# Workspace — Version 2.2.1

**Release date:** 2026-07-11
**Branch:** main
**Type:** Bug-fix & polish release (`_._._`) — block editor

---

## Overview

Version 2.2.1 is an editor-focused release: a batch of correctness fixes to
text selection, deletion, merging, undo/redo and the slash menu, a redesigned
right-click menu that puts a formatting toolbar on top, working (and removable)
inline code, an **offline spell checker with inline suggestions**, and new
**slash formatting commands** (`/bold`, `/italic`, colour and highlight). No
data format changed — pages are still plain Markdown; the formatting produced
by the new commands uses the same tiny HTML subset that already round-trips
(`<b>`, `<i>`, `<span class="tc-…">`, `<span class="bg-…">`).

---

## Fixed in 2.2.1

### Selecting all of a block and pressing Backspace/Delete
Selecting a block's whole text and pressing Backspace (or Delete) changed the
block's *type* instead of deleting the text, because the caret-at-start /
caret-at-end check fired even when a full range was selected. The custom
merge/convert now only runs for a collapsed caret; a selected range is deleted
natively.

### Backspace at the start of a block converted it to text
Pressing Backspace at the start of a heading/list/quote/callout turned it into
a plain-text block instead of merging. It now **merges the text up into the
previous block**, and the caret lands at the junction (between the previous
text and the merged-in text) rather than at the end. The convert-to-text
fallback only remains where there's nowhere to merge (the first block, or a
toggle that still has children).

### `/` opened the slash menu inside words
Typing `/` anywhere — including inside `http://`, `and/or`, `24/7` — opened the
block menu. It now opens only at the start of a block or right after
whitespace.

### The slash menu created a new block instead of changing the current one
Running a block-type command from the slash menu while the block already had
text (`hello /todo`) kept the text and added an *empty* block below. It now
**converts the current block in place**, keeping the text. Block types that
can't hold text (divider, image, code, page, database) still insert after, and
the leftover `/query` is stripped from the block.

### Inline code button did nothing / couldn't be removed
Inline code was being created correctly but had **no styling**, so it looked
unchanged. Inline `<code>` now renders as a monospace pill. The button also
**toggles** — running it on existing code (or "Clear formatting") removes it —
and the selection stays put after applying it.

### Ctrl+Z duplicated text after a merge
After Backspace merged a block up, undo restored the block but the still-focused
previous block kept showing the merged text (focused editables skip the state
→ DOM sync), duplicating content. Undo/redo now blur the active editable first
so every block re-syncs. A related stale-closure bug that made **redo** restore
an empty/old state was fixed at the same time.

### Clicking the empty space picked the last block
Clicking the empty area below the content moved the caret into the last block.
It now **adds a fresh block** to type in — unless the last block is already an
empty one, which it just focuses.

## New in 2.2.1

### One combined right-click menu with a formatting toolbar
Right-clicking a block now shows a single menu with the **format toolbar on
top** (Bold, Italic, Underline, Strikethrough, Inline code, text colour,
highlight, clear) followed by Turn into / Duplicate / Delete. The toolbar acts
on your selection, or on the **whole block** when nothing is selected. The
separate "Copy link to block" item and the "Color" submenu were removed (block
colour is now handled through the toolbar's inline colour/highlight).

### Offline spell-check with inline suggestions
The app now ships its own spell checker (browsers don't expose theirs to
JavaScript). Right-clicking a single selected word that's misspelled shows a
**Spelling** section at the top of the menu with up to four suggestions; click
one to replace the word. It uses a bundled, frequency-ordered English word list
(`public/dict/en.txt`, ~47k words) lazy-loaded on first use and cached by the
service worker, with a Norvig-style edit-distance suggester ranked by word
frequency. Everything runs client-side and works offline.

### Slash formatting commands
The slash menu gained **Format**, **Color** and **Highlight** groups: `/bold`,
`/italic`, `/red` (and every palette colour) for text colour, and
`/yellow` (etc.) for highlight. They apply the format to the current block's
text in place. Slash-menu section headers were also tidied (e.g. "Basic blocks"
→ "Basic").

## Running locally

```bash
npm install
npm run dev            # dev server — service worker disabled
# or, to exercise the PWA:
npm run build && npm run preview
```

No environment variables. Pick a **Local folder** (Chromium) or **Google Drive**
from the homepage.
