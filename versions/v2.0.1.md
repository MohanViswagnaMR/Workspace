# Workspace — Version 2.0.1

**Release date:** 2026-07-04
**Branch:** main
**Type:** Patch release (`_._.1`) — Google Drive fixes, homepage & workspace polish

---

## Overview

Version 2.0.1 builds on the 2.0.0 plain-Markdown re-architecture with a batch of
Google Drive fixes, a redesigned homepage, an in-app documentation page, and several
workspace-editor quality-of-life additions. No data format changed — everything is
still ordinary folders and Markdown files, on your computer or in your Google Drive.

---

## What's new in 2.0.1

### Google Drive — fixes
- **"Open from Drive" now works.** The Drive workspace browser modal was only rendered
  inside the connected app, so on the welcome page it opened nothing. It now renders on
  the homepage and lists every Drive workspace with an **Open** button.
- **You can see your connected Drive records.** Connected Google Drive workspaces are
  merged into the homepage **"Your workspaces"** list (deduped), not just the last-used one.
- **Reconnect when disconnected.** The browser/manage modals now re-authenticate
  automatically if the Drive session has lapsed, instead of silently showing an empty list.

### Homepage
- **Top navbar** — logo + **Workspace** title, **Docs**, **Manage workspaces**, and a
  **GitHub** link.
- **Google Drive connection status** — a cloud icon next to *Your workspaces*: green with a
  **✓** when connected, grey with an **✗** when not. Clicking it connects / refreshes.
- **Footer** — copyright on the left and a **sliding dark/light switch** on the right.
- **Default look is now dark mode with a purple (violet) accent.**

### Manage workspaces
- A dedicated **Manage workspaces** modal (from the navbar) lists every Google Drive
  workspace with **Open**, **Edit** and **Delete**.
- **Rename** a Drive workspace (renames the Drive folder) and **edit its description**
  (stored in `info.md`) inline per row.
- **Delete** permanently removes a Drive workspace folder and its files (with confirmation).

### In-app documentation
- **Docs is now a full in-app page** (previously an external link) with a sticky,
  scroll-synced table of contents covering setup, storage, blocks, databases, features,
  managing workspaces, shortcuts, persistence, project structure, tech stack, deployment
  and troubleshooting. Block-type and shortcut lists are generated from the app's own data.

### Workspace editor
- **Save-state indicator** next to the Drive/Local badge in the top bar: green **✓ Saved**,
  spinner **Saving…**, or red **✗ Unsaved** — driven by the actual write completion.
- **New page** action moved under the workspace switcher as a **glowing button**.
- **Keyboard shortcuts panel** is reachable from a button below **Settings** in the sidebar.
- **Shortcuts are shown platform-correctly** — `⌘ ⇧ L` on macOS, `Ctrl + Shift + L` elsewhere.

### Keyboard shortcuts
- **New page → `Alt + N`** (`⌥N` on Mac). `Ctrl/⌘ + N` is a reserved browser shortcut and
  cannot be captured by a web app, so the binding moved to a key the browser delivers.
- **Add a block → `Ctrl/⌘ + Enter`** — opens the block-insert menu on the current block
  (like typing `/`, without inserting the character).

## Running locally

```bash
npm install
npm run dev
# → http://localhost:5173
```

No environment variables. Pick a **Local folder** (Chromium) or **Google Drive** from the
homepage. Local data is plain Markdown you can open in any editor.
