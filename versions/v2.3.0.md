# v2.3.0 — Performance release (2026-07-11)

A performance overhaul: typing, opening Google Drive workspaces, saving, and
first load are all substantially faster. No storage-format changes — existing
workspaces work as-is.

## Editor & rendering

- **Typing latency no longer grows with workspace size.** Blocks are memoized
  (`React.memo`) and every editor handler is identity-stable (live-ref
  pattern), so a keystroke re-renders only the block being edited — previously
  every block on the page, the whole sidebar tree, and the topbar re-rendered
  on each keypress.
- **Sidebar tree is O(n).** The page tree builds one `parent → children` map
  per change instead of filtering every node per tree item (O(n²)).
- **Database views keep their state.** Table / Board / Gallery / List /
  Calendar are now top-level components instead of being re-declared inside
  `DatabaseView` on every render. Fixes two real bugs: the calendar snapping
  back to the current month after any edit, and board drag state resetting
  mid-drag. (Also fixes a latent rules-of-hooks violation in the board view.)

## Google Drive

- **Workspaces open ~5–10× faster.** Reads fetch the root entries in one
  parallel round trip, then download every folder listing, page file and
  attachment concurrently behind a global 8-requests-in-flight gate (respects
  Drive rate limits). Previously every request ran one at a time.
- **Saves upload changed files in parallel**; deletions too.
- **"Open from Drive" lists workspaces in parallel** instead of probing each
  folder sequentially.

## Saving

- The empty-folder prune (full tree walk) now runs only when a page was
  actually deleted, and the Upload/ reconcile (a directory listing per save)
  only when the set of referenced uploads changed — ordinary typing saves do
  neither.
- The IndexedDB connection is opened once and reused instead of per operation.

## Loading & bundle

- **Docs, About and Self-hosting pages are a lazy chunk** (`src/sitepages.jsx`)
  — main bundle 327 KB → 298 KB, the 32 KB chunk loads on first visit to those
  pages.
- **The 368 KB spell-check dictionary no longer competes with initial load** —
  it fetches once the editor has been idle for a moment (and warms on the first
  right-click).

## Fixes

- Text-file previews render again — uploads are blob URLs, which the old
  base64 (`atob`) path could not decode; the preview now fetches the content.
- Uploads write the file directly instead of a base64 round trip (~3× less
  memory per upload on local workspaces).
- Quick-search results refresh when pages change while the modal is open.
- Settings → About and the Docs badge show the real app version instead of a
  hardcoded "v2.1.1".
- `clone` uses `structuredClone` where available.

## Verified

Driven end-to-end headlessly (system Chrome + playwright-core against the dev
server): demo open, typing, Enter-split, backspace-merge, slash → H1
conversion, todo toggle, right-click format menu, duplicate, undo/redo,
board/table/calendar views, calendar month surviving a database edit, sidebar
tree expansion, search, lazy Docs page — all green, zero console errors.
