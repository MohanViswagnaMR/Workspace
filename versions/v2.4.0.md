# v2.4.0 — Folders, tables & customization release (2026-07-11)

A big feature release: folders, two kinds of tables, per-page tables of
contents, custom & shared templates, and much deeper appearance control.
Existing workspaces work as-is; new frontmatter fields are additive.

## Folders

- **Folders** group pages without having content of their own. On disk a
  folder is simply a directory **without** a `master page.md` — a directory
  *with* one is still a page-with-subpages. Any bare directory someone
  creates by hand shows up as a folder in the app.
- Create them with the new folder button in the Pages header or via
  **Add folder inside** on any page/folder. Clicking a folder expands it;
  empty folders show an "Empty folder" hint and persist on disk.
- Folder-appropriate context menu (rename / add page / add folder / archive /
  trash); trash & archive round-trip folders as flat `type: folder` files.
- Folders are excluded from search, dashboards and child-page lists, and
  use a simple outline icon.

## Tables

- **Simple table** — a new block: plain rows and columns of text with
  add/delete row & column controls. Stored as a plain **GFM markdown
  table**, and any hand-written pipe table in an `.md` file now opens as an
  editable simple table.
- **Smart table** — the multi-view database, now under that name in the
  slash menu (Table / Board / Gallery / List / Calendar views; every row is
  a page that can be expanded). Inline smart tables write a
  `<!--smart-table-->` marker so the two kinds round-trip correctly.
- Fixed: escaped pipes (`\|`) in table cells now survive the round trip.

## Pages

- **Side table of contents** — toggle *Show table of contents* in a page's
  ••• menu: a floating "On this page" rail lists H1/H2/H3 live, with
  click-to-scroll and a scrollspy highlight (saved as `toc: true`).
- **Footer counters** — a full-width bar at the bottom of every page shows
  live word, paragraph and block counts.
- **New page header** — the title sits next to the icon, and the icon has a
  rounded tile background. Default icons changed: iconless pages show a blue
  **Markdown mark** (pages are `.md` files), databases keep 🗄️.
- Fixed: "Remove" in the emoji picker now truly clears the icon; page covers
  no longer collapse on content-heavy pages.

## Templates

- **Save as template** on any page's ••• menu; custom templates are listed
  in Settings → Templates with Use / Remove, and can be **imported** from
  `.md` files (a `template: true` frontmatter flag — the file stays plain).
- **Template repositories** — connect any public GitHub repo holding
  template `.md` files (in `templates/` or the root) and add its templates
  with one click. The connection is saved per-workspace in `info.md`.

## Settings & appearance

- Settings is now a **sectioned modal** (920×660) with a left nav: General,
  Appearance, Templates, Plugins (placeholder) and About.
- **Font size** (Small → Extra large) scales page content, and **Google
  Fonts** can be imported by name — they appear in the Font menu and load
  automatically per workspace (`fontSize:` / `customFonts:` in `info.md`).
- The workspace font now applies **everywhere** (sidebar, topbar, modals,
  menus) — code blocks stay monospace; the homepage keeps the default font.
- Page background moved to the top of Appearance with a large preview
  (and now works in the demo).

## Homepage & chrome

- Start & welcome pages: copyright pinned bottom-left, theme switch and a
  new **accent-color dropdown** pinned bottom-right (saved in the browser).
- The sidebar has a visible **collapse button** next to the workspace name.
- Templates / Import / Storage / Archive / Trash are now a compact icon-only
  row above Settings.

## Fixes

- **Multi-block "Turn into"** (and Duplicate / Delete from the right-click
  menu) now applies to every selected block, not just the clicked one.
- The slash menu closes when the `/` is backspaced away.
